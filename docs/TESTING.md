## 修改窗口相关代码后的人工回归

| 场景 | 预期 |
| --- | --- |
| 同时打开三份 Word 文档并分别添加 | 分别显示名称，点击准确选中对应窗口 |
| 两份同名文档 | 运行时按窗口身份区分；可设别名；重启歧义时不猜测 |
| 最小化、正常、最大化窗口 | 能切换；仅恢复最小化窗口；其他状态保持 |
| Word 有保存或其他模态对话框 | 激活有效对话框，避免停留在被阻塞主窗口 |
| 关闭中间文档和最后文档 | 对应文档项移除，固定程序项保留；不将首页当成原文档 |
| 另存为或标题改变 | 默认名称更新，用户别名保持 |
| 连续快速点击不同条目 | 最后选择生效，较早请求不反向抢焦点 |
| 程序慢启动期间转去其他应用 | 工具停止延迟自动激活 |
| 托盘中运行但没有可用窗口 | 提示手动唤起，不重复启动 |
| 重启窗栏 | 固定项、排序、样式和位置恢复；文档仅在唯一匹配时恢复 |
| 断开显示器，改变缩放 | 窗栏仍可见，尺寸和点击区域正常 |
| 全透明区域 | 条目和按钮可点，其余完全透明区域不挡下面窗口 |
| 多个虚拟桌面 | 不自动跳到其他桌面或误启动同一应用 |
| 隐藏、重复启动和退出 | 托盘可恢复；同一配置单实例；退出释放图标与钩子 |
